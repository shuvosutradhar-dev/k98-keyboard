# PC Power K98 RGB Mechanical Keyboard for Android

এই প্রজেক্টটি একটি কাস্টম অ্যান্ড্রয়েড IME কীবোর্ড অ্যাপ। এটি Google Gboard-এর মতো ক্লিন লেআউট এবং PC Power K98 মেকানিক্যাল কীবোর্ডের আসল ব্লু সুইচের ক্লিক সাউন্ড, ট্যাকটাইল হ্যাপটিক্স এবং আরজিবি স্টাইলিশ গ্লো প্রদর্শন করে।

## যেভাবে APK তৈরি ও ফোনে ইনস্টল করবেন:

### উপায় ১: GitHub Actions দিয়ে একদম ফ্রিতে অনলাইনে APK তৈরি (সবচেয়ে সহজ - কম্পিউটারে কোনো সফটওয়্যার লাগবে না)
1. [GitHub](https://github.com)-এ একটি অ্যাকাউন্ট খুলুন (না থাকলে)।
2. একটি নতুন রিপোজিটরি (New Repository) তৈরি করুন।
3. এই প্রজেক্টের সব ফাইল সেই রিপোজিটরিতে আপলোড করুন।
4. রিপোজিটরির **Actions** ট্যাবে যান -> `Build K98 Keyboard APK` ওয়ার্কফ্লো দেখতে পাবেন।
5. বিল্ড শেষ হলে (১-২ মিনিটের মধ্যে) **Artifacts** সেকশনে ক্লিক করলেই আপনার ফোনে `PC-Power-K98-Keyboard-APK` (.apk) ডাউনলোড করার অপশন চলে আসবে!

### উপায় ২: Android Studio ব্যবহার করে
1. আপনার কম্পিউটারে **Android Studio** ওপেন করুন।
2. **Open Project**-এ ক্লিক করে এই ফোল্ডারটি (`PC_Power_K98_Keyboard_Project`) সিলেক্ট করুন।
3. গ্রেডল সিঙ্ক শেষ হওয়া পর্যন্ত ১ মিনিট অপেক্ষা করুন।
4. উপরের মেনু থেকে **Build > Build Bundle(s) / APK(s) > Build APK(s)**-এ ক্লিক করুন।
5. নিচে `locate` অপশন আসবে, সেখানে ক্লিক করলেই আপনার তৈরি করা `.apk` ফাইল পেয়ে যাবেন। সেটি ফোনে নিয়ে ইনস্টল করে নিন।

## ফোনে কীবোর্ড সক্রিয় করার নিয়ম:
1. ফোনে APK ইনস্টল করার পর **PC Power K98** অ্যাপটি ওপেন করুন।
2. স্ক্রিনের **১. কীবোর্ড সক্রিয় করুন (Enable)** বাটনে চাপ দিন -> লিস্ট থেকে **PC Power K98 RGB Mechanical** অন করুন।
3. এরপর **২. কীবোর্ড নির্বাচন করুন (Switch)** বাটনে চাপ দিয়ে এটি সিলেক্ট করুন।
4. ব্যস! এবার হোয়াটসঅ্যাপ, মেসেঞ্জার বা যেকোনো জায়গায় টাইপ করা শুরু করুন এবং আসল K98 ব্লু সুইচের ক্লিক সাউন্ড উপভোগ করুন!
